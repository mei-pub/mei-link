域名接入管理

主域名（如 meichuanxue.com）：启用 frps 子域名功能（subDomainHost）。客户端填子域名（如 admin），访问地址为 admin.meichuanxue.com。需在 DNS 将 *.meichuanxue.com 泛解析到本服务器。
泛域名（如 *.apps.meichuanxue.com）：登记到域名目录，客户端 HTTP/HTTPS 隧道用「自定义域名」填该域名，用于将该泛域名下的请求路由至同一隧道。DNS 需添加同名泛解析。
额外域名（如 photo.example.com）：单域名，客户端在隧道自定义域名中填该完整域名。DNS 需解析到本服务器。
注意：frp 只支持一个 subDomainHost；额外域名和泛域名不能与主域名的子域名范围重叠。
